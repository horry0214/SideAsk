Static Single Assignment

In SSA form, every variable is assigned exactly once, making optimization and data-flow analysis easier.

At control-flow merge points, a phi node selects the value associated with the predecessor block that was actually taken.

The intuition

A phi node is a value selector at a control-flow merge. It does not run like a normal function.

In this example

x₂ = phi(x₀, x₁)
  • Arrived from block A → choose x₀
  • Arrived from block B → choose x₁
SSA keeps one assignment per variable version while still representing merged control flow.
