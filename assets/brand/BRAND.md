# SideAsk Brand

## Canonical asset

`sideask-logo.png` 是本项目当前批准的 canonical wordmark，来自产品方提供的正式 Logo 原图，不应重新绘制或改变比例。

`sideask-icon.png` 与 `icon-*.png` 从 canonical PNG 中的 S 图形机械裁切、居中和缩放生成。`sideask-icon.svg` 是供小尺寸 UI 内联使用的忠实矢量近似；正式设计源文件可用时，应由设计源替换它，而不是修改 canonical PNG。

## Name and slogans

- Product: **SideAsk**
- Chinese: **问题走支线，思路留主线。**
- English: **Ask aside. Stay on track.**
- Category: **AI 支线提问助手 / AI Side-Question Layer**

## Usage

- 保持 Logo 四周至少一个端点直径的留白。
- 不拉伸、不旋转、不改变渐变方向。
- 不加入机器人、sparkle、发光或复杂背景。
- 浮窗中优先使用 icon；README 和发布页使用 wordmark。
