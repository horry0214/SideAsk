# Submission Checklist

## Before both submissions

- [ ] Register and verify the publisher/developer accounts.
- [ ] Enable two-step verification on the Chrome Web Store publisher account.
- [ ] Confirm that `manifest.json` is at the root of each upload ZIP.
- [ ] Confirm version `0.4.0` is greater than any previously uploaded version.
- [ ] Upload the stable `sideask-gateway.zip` asset to the matching public GitHub release.
- [ ] Verify both privacy-policy URLs are publicly accessible.
- [ ] Verify support and homepage links.
- [ ] Test the complete reviewer flow in a clean Chrome profile and a clean Edge profile.

## Chrome Web Store

- [ ] Upload `sideask-chrome-web-store-v0.4.0.zip`.
- [ ] Add English and Simplified Chinese listing copy.
- [ ] Upload `store-assets/shared/icon-128.png`.
- [ ] Upload `store-assets/shared/promo-small-440x280.png`.
- [ ] Upload `store-assets/shared/promo-marquee-1400x560.png` (optional but prepared).
- [ ] Upload up to five localized 1280×800 screenshots from each language folder.
- [ ] Complete single-purpose, permission, remote-code, and data-use declarations using `PRIVACY-DECLARATIONS.md`.
- [ ] Add the Chrome privacy-policy URL.
- [ ] Paste `REVIEW-NOTES.md` into reviewer notes.
- [ ] Start with Trusted testers if desired, then submit for public review.

## Microsoft Edge Add-ons

- [ ] Upload `sideask-edge-addons-v0.4.0.zip` in Partner Center.
- [ ] Select Productivity and the intended markets.
- [ ] Complete the Privacy page using `PRIVACY-DECLARATIONS.md`.
- [ ] Add the Edge privacy-policy URL.
- [ ] Create English and Simplified Chinese store listings.
- [ ] Upload `store-assets/shared/edge-logo-300.png` for each language.
- [ ] Upload the 440×280 and 1400×560 promotional tiles.
- [ ] Upload up to six 1280×800 screenshots per language; five are prepared.
- [ ] Paste `REVIEW-NOTES.md` into Notes for certification.
- [ ] Submit for certification.
