# SideAsk Store Submission Kit

This directory contains the text and policy material for submitting SideAsk 0.7.0 to Chrome Web Store and Microsoft Edge Add-ons.

## Upload files

- Chrome package: `sideask-chrome-web-store-v0.7.0.zip`
- Edge package: `sideask-edge-addons-v0.7.0.zip`
- Browser download: `sideask-browser-extension-v0.7.0.zip`
- Gateway companion: `sideask-local-gateway-v0.7.0.zip`
- Shared images: `store-assets/shared/`
- English screenshots: `store-assets/en/screenshots/`
- Simplified Chinese screenshots: `store-assets/zh-CN/screenshots/`

The Chrome and Edge ZIP files intentionally contain only the extension, with `manifest.json` at the ZIP root. Store images and submission notes are uploaded separately.
