Static Single Assignment (SSA)

In SSA form, every variable is assigned exactly once. At control-flow merge points, a phi node selects the value that corresponds to the predecessor block actually taken.

if (cond) x = 1; else x = 2;
x2 = phi(x0, x1)

Phi nodes are not normal functions executed at runtime. They are a representation used by the compiler to make data flow explicit before later optimization passes.
